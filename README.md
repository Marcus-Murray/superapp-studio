# Superapp Studio

A modular, world-class A+ codebase for a tablet-first superapp that blends:

- Figma-like ideation, whiteboarding, wireframing
- Notion-like docs, tasks, and project management
- AI code generation that syncs designs/ideas to IDE-ready boilerplates

Target device: Samsung S10 FE+ tablet (Android). Cross-platform foundation with a TypeScript monorepo.

## Vision (high-level)
- Sketch, ideate, and wireframe on tablet while out for coffee.
- Auto-sync sessions to an AI pipeline that generates boilerplate projects.
- Manage projects, docs, and tasks within the same app.
- Return to PC with ready-to-run starter repos.

## Monorepo structure
- apps/ — end-user apps (mobile, web, desktop later)
- packages/ — shared libraries (ui, core, ai, sync, schema, tooling)
- docs/ — design vision, architecture, roadmap

## Getting started
- This repository is scaffolded for npm workspaces.
- After cloning: `npm install` to set up workspaces (once they are added).
